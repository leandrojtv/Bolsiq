# Capturas do apps/web

Telas de `/ativo/PETR4` com dados reais (backfill desde 2024), geradas por
`pnpm --filter @bolsiq/web capturas` em 390, 768 e 1440 px. Servem para
comparar a olho com [Main.dc.html](../Main.dc.html) e
[AtivoMobile.dc.html](../AtivoMobile.dc.html); não são referência de teste,
porque o dado muda todo dia.
